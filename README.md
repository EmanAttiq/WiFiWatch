# WiFiWatch

WiFiWatch is a Python-based passive wireless network monitoring and security auditing tool developed for educational and authorized lab use.

## Features

- Discover nearby wireless access points.
- Identify SSIDs, BSSIDs, channels and signal information.
- Passively observe wireless client activity and AP relationships.
- Audit wireless security, including WPA/WPA2/WPA3, encryption ciphers, authentication methods and WPS.
- Identify possible rogue or evil-twin access point candidates using an optional trusted baseline.
- Analyze access point distribution across wireless channels.
- Generate TXT and JSON reports.
- Continuously monitor for newly discovered access points.

## How It Works

WiFiWatch performs passive wireless network monitoring by capturing and analyzing Wi-Fi frames using Python and the Scapy packet-processing library. It operates through a wireless network adapter configured in monitor mode, allowing it to observe supported wireless traffic within the adapter's reception range without actively interacting with access points or clients.

The tool processes captured wireless frames to identify access points and wireless clients. It extracts relevant information, including Service Set Identifiers (SSIDs), Basic Service Set Identifiers (BSSIDs), channel numbers, and available signal information. It also examines observed client activity and records potential relationships between clients and access points based on the frames captured.

### Wireless Security Analysis

WiFiWatch examines wireless security information advertised in supported management frames, particularly beacon and probe response frames. It analyzes security-related information elements to identify advertised encryption protocols, cipher suites, and authentication methods.

Based on the available information, it can identify security configurations such as WPA, WPA2, and WPA3, detect the presence of outdated TKIP encryption, and check for advertised Wi-Fi Protected Setup (WPS) information.

### Rogue Access Point Detection

WiFiWatch supports an optional trusted access point baseline supplied through an external JSON file. It compares observed access points against the trusted SSIDs, BSSIDs, and security settings in that baseline.

When an access point advertises a trusted SSID but has a different BSSID or security configuration, WiFiWatch can flag it as a potential rogue or evil-twin candidate. These alerts indicate a mismatch requiring further investigation; they do not independently confirm malicious activity.

### Channel Analysis and Reporting

The tool organizes discovered access points by their operating channels to identify channel concentration and possible overlapping channel usage. This provides a basic overview of wireless channel distribution and potential congestion.

After processing the captured information, WiFiWatch generates TXT and JSON reports containing discovered access points, observed clients, security audit results, potential rogue access point findings, and channel analysis.

WiFiWatch also supports importing CSV files generated by airodump-ng, allowing users to analyze previously collected wireless network information without performing a live capture.

### Passive Monitoring and Responsible Use

WiFiWatch is designed for passive monitoring and educational security auditing. It observes and analyzes wireless frames received by the monitoring adapter; it does not transmit deauthentication frames, inject packets, attempt unauthorized connections, or perform password cracking.

All testing should be conducted only on networks owned by the user or where explicit authorization has been granted.

## Requirements

- Kali Linux or another Linux distribution.
- Python 3.
- A wireless adapter that supports monitor mode.
- Scapy.

## Installation

Clone the repository:

```bash
git clone https://github.com/EmanAttiq/WiFiWatch.git
cd WiFiWatch
```
Install the required dependencies:

pip install -r requirements.txt

## Usage

### Live passive monitoring

```bash
sudo python3 wifiwatch.py --interface wlan0
```

### Continuous watch mode

```bash
sudo python3 wifiwatch.py --interface wlan0 --watch
```

### Use an optional trusted baseline

Create your own `baseline.json` using the format in `baseline.example.json`.

```bash
sudo python3 wifiwatch.py --interface wlan0 --baseline baseline.json --watch
```

### Import an airodump-ng CSV file

```bash
python3 wifiwatch.py --csv capture1-01.csv
```

## Reports

WiFiWatch generates:

- `wifiwatch_report.txt`
- `wifiwatch_report.json`

Reports include discovered access points, client observations, security audit results, rogue AP candidates and channel analysis.

 ## Project Limitations

- Detection accuracy depends on the wireless adapter's monitor-mode capabilities, supported frequencies, signal reception, and the availability of captured wireless frames.

- Rogue AP detection relies on the accuracy and completeness of the user-provided trusted baseline. It identifies possible impersonation of trusted SSIDs through BSSID or security mismatches but cannot confirm malicious activity or detect every rogue access point.

- Client-to-access-point relationships are inferred from observed wireless frames. They represent potential relationships and should not always be interpreted as confirmed client associations.

- Channel congestion and overlap results are approximate estimates based on observed access point distribution and channel numbers. They do not measure actual radio-frequency interference or signal quality.

- Hidden SSIDs, limited packet captures, weak signals, and unavailable management information may prevent WiFiWatch from collecting complete access point, client, or security details.
