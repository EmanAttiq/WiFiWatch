# WiFiWatch

WiFiWatch is a Python-based passive wireless network monitoring and security auditing tool developed for educational and authorized lab use.

## Features

- Discover nearby wireless access points.
- Identify SSIDs, BSSIDs, channels and signal information.
- Passively observe wireless client activity and AP relationships.
- Audit wireless security, including WPA/WPA2/WPA3, encryption ciphers, authentication methods and WPS.
- Identify possible rogue or evil-twin access point candidates using an optional trusted baseline.
- Analyze access point distribution across wireless channels.
- Generate TXT and JSON reports.
- Continuously monitor for newly discovered access points.

## How it works

WiFiWatch uses Python and Scapy to inspect wireless management and data frames captured through a wireless adapter in monitor mode. It can also import CSV files generated by airodump-ng.

The tool does not send deauthentication packets, perform wireless attacks, or crack passwords. Its monitoring and analysis are passive.

## Requirements

- Kali Linux or another Linux distribution.
- Python 3.
- A wireless adapter that supports monitor mode.
- Scapy.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/WiFiWatch.git
cd WiFiWatch
```

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

### Live passive monitoring

```bash
sudo python3 wifiwatch.py --interface wlan0
```

### Continuous watch mode

```bash
sudo python3 wifiwatch.py --interface wlan0 --watch
```

### Use an optional trusted baseline

Create your own `baseline.json` using the format in `baseline.example.json`.

```bash
sudo python3 wifiwatch.py --interface wlan0 --baseline baseline.json --watch
```

### Import an airodump-ng CSV file

```bash
python3 wifiwatch.py --csv capture1-01.csv
```

## Reports

WiFiWatch generates:

- `wifiwatch_report.txt`
- `wifiwatch_report.json`

Reports include discovered access points, client observations, security audit results, rogue AP candidates and channel analysis.

## Important limitations

- Rogue AP detection identifies possible impersonation of SSIDs included in the trusted baseline. It does not prove that an AP is malicious or detect every rogue AP.
- Client-to-AP relationships are observations, not necessarily confirmed associations.
- Channel overlap analysis is an approximation, not a measurement of actual radio-frequency interference.
- Results depend on adapter capabilities, capture conditions and available wireless frames.

## Project scope and responsible use

WiFiWatch is intended strictly for passive monitoring of networks you own or are explicitly authorized to assess.

Do not use it to monitor networks without permission. No active attacks, password cracking or unauthorized access are part of this project.
